# GHGP — 그린홈시스 영업용 소개 페이지

영업 사원이 고객에게 문자로 보내는 단일 정적 페이지입니다. (`index.html`)

## 페이지 구성

1. **히어로** — 포인트 적립 서비스 오픈 홍보 + 신뢰 배지
2. **웹툰** — 창호 견적의 어려움 → 그린홈시스가 해결 (4컷)
5. **마감 CTA** — 전화 유도, 모바일에서는 하단 플로팅 전화 버튼 고정

메뉴의 **자료실**(`archive.html`), **사례&리뷰**(`reviews.html`), **견적서 받기**(`quote.html`)는
같은 스타일을 쓰는 별도 페이지입니다. "견적서 받기"는 고객이 휴대폰 번호+문자 인증으로
본인의 가견적서만 확인하는 화면입니다. 뒷단(문자 인증·저장·가견적서 배정)은 그린홈시스
지원 콘솔(`greenhome-mileage` 저장소)이 맡습니다 — 이 페이지는 화면만 그리고,
`https://gh-point.com/api/public/quote/*` 를 부릅니다(2026-09-22, "가견적서 기능은
전부 지원 콘솔로"). 가견적서를 보내거나 회수하는 것은 지원 콘솔의 [가견적서] 화면에서
합니다.

## 배포

- **Replit Static 배포**: https://gh-gp.replit.app (GitHub 저장소 Import 방식)
- main 브랜치 변경 후 Replit 워크스페이스에서 Git pull → Republish 하면 반영됩니다.

## 운영 방법

- **자료실(archive.html) 자료 추가**: 파일을 `assets/`에 올린 뒤, `archive.html`의 `doc-item` 블록을
  복사해 제목·경로만 바꾸면 됩니다. PDF는 `href`+`download`, 이미지는 `data-full`(크게 보기)로 연결하세요.

- **월간 프로모션 교체**: `assets/promo-monthly.png` 파일만 새 포스터로 갈아끼우고,
  `index.html`에서 `8월 한정` 뱃지 텍스트와 카드 제목을 해당 월에 맞게 수정하면 됩니다.
