# 그린홈시스 방문 집계 · 대시보드 설치 안내

우리 사이트들의 방문 기록을 **직접 집계**해서, 관리자만 볼 수 있는 대시보드 하나에서 확인하는 구성입니다.
외부 분석 서비스를 쓰지 않고, 데이터는 전부 우리 Cloudflare 계정에 쌓입니다.

**사이트가 여러 개여도 대시보드는 하나입니다.** 각 사이트에 같은 집계 코드를 넣고
`SITE` 값만 다르게 적어주면, 대시보드 위쪽 선택 메뉴에서 사이트별로 골라 보거나 한 번에 비교할 수 있습니다.

```
영업 페이지     ┐
그린홈시스 홈페이지 ├→ Cloudflare Worker → D1 데이터베이스
비아블랑 홈페이지  ┘                          ↑
                        관리자 → 대시보드 (비밀번호 로그인)
```

### 사이트 코드

| 사이트 | SITE 값 |
|---|---|
| 영업 페이지 (ghgp.replit.app) | `ghgp` |
| 그린홈시스 홈페이지 | `home` |
| 비아블랑 홈페이지 | `viablanc` |

## 파일

| 파일 | 설명 |
|---|---|
| `worker.js` | 집계 서버 + 대시보드 화면 (Cloudflare Worker에 붙여넣는 코드) |
| `schema.sql` | 기록이 쌓일 표 구조 |
| `snippet.html` | 다른 사이트(워드프레스 등)에 붙여넣는 집계 코드 |

---

## 설치 순서 (한 번만, 약 10분)

### 1. 데이터베이스 만들기
1. Cloudflare 대시보드 → 왼쪽 메뉴 **Storage & Databases → D1**
2. **Create database** → 이름 `ghgp-analytics` → 생성
3. 만들어진 DB의 **Console** 탭에 `schema.sql` 의 **내용**(파일 이름이 아니라 SQL 글자)을 붙여넣고 실행
4. **Tables** 목록에 `hits` 가 보이면 성공

### 2. Worker 만들기
1. 왼쪽 메뉴 **Workers & Pages** → **Create** → **Workers** → **Start with Hello World!**
2. 이름 `ghgp-stats` → **Deploy**
3. **Edit code** 를 눌러 편집기를 열고, 기존 코드를 전부 지운 뒤 `worker.js` 내용을 붙여넣고 **Deploy**

### 3. Worker에 설정값 연결
Worker 화면 → **Settings**

**Bindings → Add binding → D1 database**
- Variable name: `DB` ← 반드시 이 이름
- Database: 1번에서 만든 `ghgp-analytics`

**Variables and Secrets → Add**

| 이름 | 종류 | 값 | 필수 |
|---|---|---|---|
| `DASH_PASSWORD` | Secret | 대시보드 로그인 비밀번호 (직접 정하세요) | 필수 |
| `SECRET` | Secret | 아무 무작위 문자열 40자 정도 | 필수 |
| `ALLOW_ORIGIN` | Text | 집계를 허용할 사이트 주소, **쉼표로 구분**<br>예: `https://ghgp.replit.app,https://greenhomesys.com` | 필수 |
| `SITE_NAMES` | Text | 사이트 코드와 표시 이름<br>예: `ghgp=영업 페이지,home=그린홈시스 홈페이지,viablanc=비아블랑 홈페이지` | 선택 |

> `DASH_PASSWORD` 와 `SECRET` 은 누구에게도 알려주지 마세요. 설치를 돕는 사람에게도 필요 없는 값입니다.

저장 후 **Deploy** 를 한 번 더 누릅니다.

### 4. 사이트에 집계 코드 켜기
각 사이트 HTML 맨 아래 집계 코드에서 두 줄을 채웁니다.

```js
var ENDPOINT = 'https://ghgp-stats.○○○.workers.dev/collect';  // Worker 주소 + /collect
var SITE = 'ghgp';   // 이 사이트를 구분할 이름
```

- `ENDPOINT` 는 모든 사이트가 **같은 주소**를 씁니다.
- `SITE` 만 사이트마다 다르게: 영업 페이지 `ghgp`, 그린홈시스 홈페이지 `home`, 비아블랑 홈페이지 `viablanc`
- `ALLOW_ORIGIN` 에 그 사이트 주소를 추가하는 것도 잊지 마세요. 빠지면 기록이 거부됩니다.

`ENDPOINT` 가 비어 있으면 집계 코드는 아무 일도 하지 않으므로, 설정 전까지 사이트에 아무 영향이 없습니다.

## 집계 코드를 넣을 수 없는 곳 (네이버 블로그, 리틀리 등)

네이버 블로그·리틀리처럼 **남의 플랫폼 위에 있는 페이지에는 집계 코드를 넣을 수 없습니다.**
그 서비스들이 외부 스크립트 삽입을 막아두기 때문입니다. 그래서 "블로그 방문자 수"는 이 대시보드에
나오지 않고, 각 서비스가 제공하는 자체 통계 화면에서 보셔야 합니다.

대신 **거기서 우리 사이트로 얼마나 넘어왔는지**는 정확히 집계할 수 있습니다.
링크 끝에 `?from=` 표시를 붙여두면 됩니다.

| 링크를 거는 곳 | 이렇게 링크 |
|---|---|
| 네이버 블로그 | `https://ghgp.replit.app/?from=blog` |
| 리틀리 | `https://ghgp.replit.app/?from=littly` |
| 인스타그램 | `https://ghgp.replit.app/?from=insta` |
| 카카오톡·문자 | `https://ghgp.replit.app/?from=kakao` |
| 명함 QR코드 | `https://ghgp.replit.app/?from=card` |

대시보드의 "유입 경로"에 각각 **네이버 블로그 / 리틀리 / 인스타그램 / 카카오톡 / 명함 QR** 로 표시됩니다.
표시된 이름은 방문자가 사이트 안에서 페이지를 옮겨 다녀도 유지됩니다.

> 네이버·리틀리는 유입 정보를 넘겨주지 않는 경우가 많아, 이 표시를 붙이지 않으면
> "직접 접속"으로 뭉뚱그려 집계됩니다. 링크를 새로 걸 때 습관처럼 붙여두시면 좋습니다.

## 사이트를 나중에 추가할 때

1. `snippet.html` 내용을 새 사이트의 `</body>` 앞에 붙여넣고 `SITE` 값만 새로 정합니다
2. Worker 설정의 `ALLOW_ORIGIN` 에 새 사이트 주소를 쉼표로 이어 붙입니다
   (`www` 주소로도 접속된다면 그 주소까지 함께)
3. `SITE_NAMES` 에 표시 이름을 추가합니다 (선택)

데이터베이스나 Worker를 새로 만들 필요는 없습니다.

### 워드프레스 사이트에 넣기

관리자 화면에서 **테마 파일을 직접 고치지 말고** 아래 중 한 가지 방법을 쓰세요.
테마를 고치면 테마가 업데이트될 때 코드가 사라집니다.

**방법 A — 코드 삽입 플러그인 (권장)**
1. 플러그인 → 새로 추가 → `WPCode` 또는 `Header Footer Code Manager` 검색 후 설치·활성화
2. 새 코드(Snippet) 추가 → 종류는 **HTML** 또는 **Universal**
3. `snippet.html` 내용을 붙여넣고, 위치를 **Footer(본문 끝)** 로 지정
4. 활성화 후 저장

**방법 B — 테마에 코드 삽입 칸이 있는 경우**
외모 → 사용자 정의하기(또는 테마 설정)에 "추가 코드 / 푸터 스크립트" 칸이 있으면 거기에 붙여넣습니다.

넣은 뒤 사이트를 시크릿 창으로 열어보고, 대시보드에 그 사이트가 나타나는지 확인하세요.

## 사용법

- **대시보드 주소**: Worker 주소 그대로 (예: `https://ghgp-stats.○○○.workers.dev`)
- 비밀번호를 넣으면 12시간 동안 로그인이 유지됩니다. 검색엔진에는 노출되지 않습니다.

### 보이는 항목
- 오늘/기간 방문자·조회수, 일별 방문자 추이 그래프
- **사이트별 비교** (사이트가 둘 이상일 때 자동 표시)
- 페이지별 조회수
- 유입 경로 (네이버·블로그·숨고·구글·직접 접속 등)
- 버튼·자료 클릭 (전화, 포인트 서비스, 카탈로그·시스템창호 열람, 자료 다운로드, 블로그·숨고 클릭, 견적/거래처 문의, 영상 재생)
- 기기 비율(모바일/PC), 시간대별 방문 분포

### 내 방문을 집계에서 빼기
확인용으로 자주 들어가는 기기에서 주소 뒤에 `?notrack=1` 을 붙여 한 번 열면
(예: `https://ghgp.replit.app/?notrack=1`) 그 기기·브라우저의 방문은 이후 집계되지 않습니다.

## 개인정보 처리

- **IP 주소를 저장하지 않습니다.** 방문자 구분용 임시 식별자를 만들 때만 잠깐 쓰이고, 되돌릴 수 없는 해시로 바꾼 뒤 버립니다.
- 이 식별자는 **날짜가 바뀌면 초기화**되므로 날짜를 넘겨 같은 사람을 추적할 수 없습니다.
- 방문자에게 쿠키를 심지 않습니다. (관리자 로그인 쿠키만 예외)
- 이름·연락처 등 개인을 특정할 수 있는 정보는 일절 수집하지 않습니다.

## 비용

Cloudflare 무료 요금제 범위 안에서 동작합니다.
(Worker 하루 10만 요청, D1 하루 500만 행 읽기 — 사이트 몇 개를 합쳐도 여유가 큽니다.)

## 참고

- Replit Growth 탭의 숫자와는 집계 기준이 달라 값이 조금 다를 수 있습니다. 둘 다 정상입니다.
- 숨고 리뷰 수, 네이버 블로그 조회수처럼 다른 회사 사이트 안의 숫자는 외부에서 가져올 수 없어 이 대시보드에 자동 표시되지 않습니다.
